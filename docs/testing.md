# Тестирование

Здесь записано только то, что действительно запускалось, и с каким результатом. Время — по Москве (MSK).
Стенд: Docker на Linux, PHP **8.4.28**, MySQL **8.4.13**, 1С-Битрикс «Малый бизнес» (пробная):
main 26.150.0, iblock 25.300.0, catalog 25.550.0, sale 26.0.0. Playwright 1.65 (Chromium) запускался на хосте.

## Что входит в раунд

`docker/round.sh` выполняет по порядку (любой ненулевой код — раунд красный):

1. `docker/check-repo.sh` — в git нет ядра, файлов с доступами и литералов паролей;
2. php-cs-fixer (`--dry-run`), PHPStan level max (стабы `local/stubs`), tsc, ESLint, Prettier, сборка Vite;
3. `docker/test-db.sh` — свежая тестовая база `bitrix_shop_classic_test` (копия структуры рабочей базы);
4. PHPUnit — все наборы на тестовой базе (функциональные — HTTP через nginx на тестовом сайте :8097);
5. `cli/fixtures.php` — свежие демо-данные на рабочей базе;
6. Playwright e2e `--project=e2e` против :8096.

- `e2e/purchase.spec.ts` — гость: каталог → раздел → карточка → корзина (2 шт.) → «Оформить заказ» → вход покупателя →
